# 布局参考蓝图

## 宏观首页

- 顶部窗口栏：`Quantum Monitor V3.0`
- 左侧导航：宏观首页、币安合约、国内股票、国内期货、外盘期货、全局设置
- 顶部控制区：
  - 宏观首页显示首页总开关、布局切换、添加卡片
  - 币安合约显示监控 Top N、搜索和刷新状态
- 主视图区：
  - 全球核心股指卡片
  - 全球宏观风向标卡片
  - 7x24 实时快讯流
- 底部状态栏：
  - 当前连接
  - 数据包收发状态
  - 核心内存
  - 休市状态

## 币安合约页

- 表格列：
  - 品种
  - 最新价格
  - 24H 涨幅
  - 1 分钟 MA60 偏离
  - 15 分钟偏离
  - 日线偏离
  - 图表入口
- 交互：
  - 支持按列排序
  - 支持搜索币种
  - 点击图表按钮按需打开 TradingView

## 图表弹窗

- 标题：`{symbol} 币安极速图表窗口`
- 顶部按钮：`1分钟`、`15分钟`、`日线`
- 右上角关闭按钮必须显式销毁实例
- 币安合约使用 TradingView 嵌入图表，并通过 `MASimple@tv-basicstudies` 显示 MA60
