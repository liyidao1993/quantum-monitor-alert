# Quantum Monitor 开发文档

更新时间：2026-05-05

## 目标

本项目的目标是一个模块化、轻量化、UI 与底层解耦的监控预警系统。

核心原则：

- UI 只消费标准事件和标准数据，不直接理解某个交易所 API。
- 每个市场模块独立运行、独立销毁、独立维护符号映射和数据源。
- 后台不长期绘制或缓存 K 线，指标尽量使用轻量快照和即时价格计算。
- 预警由独立 `AlertEngine` 处理，市场模块只负责产出标准 tick。

## 当前架构

```text
Market Module -> EventBus -> AlertEngine -> Alert Event
              -> EventBus -> SSE -> React UI
```

主要目录：

- `1_Core_Engine/ConfigManager`：读取和保存 `settings.json`
- `1_Core_Engine/EventBus`：模块与 UI 的唯一事件通道
- `1_Core_Engine/LifecycleController`：模块启动、停止、销毁
- `1_Core_Engine/AlertEngine`：统一预警判断和冷却
- `2_Market_Modules/Crypto_Binance`：币安合约 Top 成交量监控
- `2_Market_Modules/Stocks_US`：美股按需数据层
- `2_Market_Modules/Futures_CN`：国内期货数据层
- `2_Market_Modules/Futures_Global`：外盘期货数据层
- `4_Shared_Types`：标准数据契约、符号映射、数据质量工具

前端主要边界：

- `src/App.tsx`：应用壳、导航、全局状态编排。
- `src/views/BinanceView.tsx`：币安合约成交量 Top 列表视图。
- `src/views/StocksUsView.tsx`：美股按需视图。
- `src/views/FuturesCnView.tsx`：国内期货按需视图。
- `src/views/FuturesGlobalView.tsx`：外盘期货按需视图。
- `src/views/MacroHomeView.tsx`：宏观首页静态视图。
- `src/views/SettingsView.tsx`：全局设置、API 地址、分类预警和通知设置视图。
- `src/components/ChartWindow.tsx`：按需 K 线图表窗口。

## 市场模块边界

| 模块 | 职责 | 当前数据源 | 图表策略 |
| --- | --- | --- | --- |
| `Crypto_Binance` | 币安 U 本位合约成交量前 50 | Binance Futures REST / WS | 按需打开图表，不做后台 K 线绘制 |
| `Stocks_US` | 美股候选数据层 | Yahoo Finance Chart | 独立 UI，按需 HTTP 拉取 |
| `Futures_CN` | 国内期货候选数据层 | Sina Futures | 独立 UI，按需 HTTP 拉取 |
| `Futures_Global` | 外盘期货美黄金、纳指、标普、原油等候选数据层 | Yahoo Finance Chart | 独立 UI，按需 HTTP 拉取 |

币安合约不走自定义币种列表，目标是监控成交量前 50。国内期货、外盘期货后续可以拥有各自的自选逻辑，但不能污染币安模块。

## 标准 Tick

UI 和预警只消费 `StandardMarketTick`：

```ts
interface StandardMarketTick {
  market: MarketModuleName;
  symbol: string;
  price: number;
  change_24h: number;
  ma60_dev_1m?: number;
  ma60_dev_15m?: number;
  ma60_dev_1d?: number;
  updated_at: string;
}
```

## 币安图表与计算边界

币安合约模块负责成交量 Top50、实时价格、24H 涨跌、MA60 偏离值和瞬时涨跌预警。

- 启动和周期刷新时只拉最近 60 根 close，用于计算 `1m` / `15m` / `1d` MA60 偏离。
- 后台只保存 `sum59` 数字快照，不保存完整 K 线数组。
- 不做本地图表绘制，不维护图表缓存。
- 图表按需打开 TradingView，由 TradingView 自己加载 K 线并用 `MASimple@tv-basicstudies` 显示 60 均线。

这样符合轻量化目标：后台只为表格指标维护小型数值快照，图表查看完全按需。

## 全局 API 设置

所有外部接口集中显示在全局设置，并保存到：

```text
Quantum_Monitor_System/1_Core_Engine/settings.json
```

当前字段：

- `binance_fapi_base`
- `binance_ws_base`
- `binance_use_all_ticker_stream`
- `socks_proxy`
- `https_proxy`
- `sina_min_line_url`
- `sina_quote_url`
- `yahoo_chart_base`
- `tradingview_widget_url`

后端接口：

- `GET /api/settings`：读取完整设置
- `POST /api/settings`：保存完整设置并发布 `SettingsUpdated`
- `GET /api/settings/test-endpoints`：测试 Binance、Sina、Yahoo 外盘、Yahoo 美股、TradingView 当前连通性
- `GET /api/stocks-us/klines`：美股按需 K 线接口，当前支持 `1m`、`15m`、`1d`，示例 `symbol=AAPL`
- `GET /api/futures-cn/klines`：国内期货按需 K 线接口
- `GET /api/futures-global/klines`：外盘期货按需 K 线接口，当前支持 `1m`、`15m`，示例 `symbol=GC1!` 或 `symbol=NQ1!`

保存后，REST 类请求会读取新的环境配置；已有 WebSocket 连接建议重启模块或重启服务后完全切换。

国内期货说明：

- 分钟线使用新浪 `InnerFuturesNewService.getFewMinLine`。
- 最新价/名称/成交量使用新浪 `hq.sinajs.cn/list=nf_品种`。
- 新浪行情返回 GB18030，客户端会显式解码，避免中文乱码。
- 休市日使用最近交易日 quote/K 线判断为可用，不用 30 分钟内更新作为硬条件。
- 实时监控由 `FuturesCnMonitorModule` 负责，模块启动才轮询，模块停止即清理 timer。
- 国内期货 MA60 参考项目实现：分别读取 `1m`、`15m` 最近 60 根 close，求平均得到 MA60，再用 quote 最新价计算偏离。

## 预警设计

`AlertEngine` 独立订阅通用 `MarketDataUpdated` 标准 tick，并发布 `AlertRaised`。预警文案已改为中文。

全局设置里的分类预警只控制“瞬时涨跌”，不是 MA60 偏离：

- 虚拟货币：当前对应 `Crypto_Binance`，默认 30 秒涨跌 5%
- 期货：当前对应 `Futures_CN` 和 `Futures_Global`，默认 60 秒涨跌 1%
- 其它：当前对应 `Stocks_CN` 和 `Macro_Home`

底层仍保存为 `AlertSettings.thresholds[市场模块]`，这样每个模块保持独立，UI 只把多个模块组合成更容易维护的类别。

当前已实装预警类型：

- `instant_move`：窗口内瞬时波动越界

币安在本地轻量计算 MA60 偏离作为表格指标，但不以 MA60 偏离触发预警。需要观察均线时打开 TradingView 图表。
- `module_error`：预留
- `data_quality`：预留

## 部署方向

本地固定端口 `3000`。Google Cloud 优先考虑 Cloud Run：

- `PORT` 使用平台注入，本地默认 3000。
- API 密钥和机器人 token 放 Secret Manager 或 Cloud Run env。
- 健康检查使用 `/api/health`。
- 运行日志进入 Cloud Logging。
- Binance Global Futures 需要可访问 Global Futures 的出口区域；美国出口大概率不能直接替代。
## 刷新间隔与轻量缓存

刷新间隔统一放在 `RefreshIntervalSettings`，按大品种独立配置：
- `price_seconds`：价格、涨跌幅、瞬时预警的刷新/推送节奏。
- `ma60_1m_seconds`：1 分钟 MA60 偏离快照刷新节奏。
- `ma60_15m_seconds`：15 分钟 MA60 偏离快照刷新节奏。
- `ma60_1d_seconds`：日线 MA60 偏离快照刷新节奏。

当前默认值：
- 币安合约：价格 1 秒，1m MA60 60 秒，15m MA60 300 秒，日线 MA60 3600 秒。
- 国内期货：价格 15 秒，MA60 默认 60/300/3600 秒；当前国内期货模块的 MA60 随轮询刷新。
- 外盘期货、美股、国内股票、宏观首页已在配置层预留独立刷新参数，后续模块接入时不得复用其它品种的调度器。

币安合约使用 `.runtime/ma60_snapshots_binance.json` 保存轻量 `sum59` 快照和更新时间，只缓存数字，不缓存完整 K 线，不做本地图表绘制。启动时优先复用未过期快照，过期后按品种分批补拉最新 close。
