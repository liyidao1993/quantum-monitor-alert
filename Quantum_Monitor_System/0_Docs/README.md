# Docs

这里存放项目事实来源、架构文档、布局蓝图和开发进度记录。

当前最高优先级文档：

- `开发文档.md`：当前架构、数据契约、配置和部署方向。
- `执行计划_模块拆分与告警.md`：模块拆分、轻量化约束和后续开发顺序。
- `进度记录.md`：真实开发进度、已完成项和待验证项。
- `架构审查_2026-05-04.md`：当前解耦状态、DeepSeek 审核吸收项和剩余风险。
- `布局参考蓝图.md`：桌面 UI 初始布局参考。

维护规则：

- 代码行为、接口、数据源或架构发生变化时，同步更新文档。
- 文档以当前项目实际状态为准，不保留误导性的旧阶段描述。
- 后续目标始终围绕模块化、轻量化、UI 与底层解耦、品种逻辑互不干涉。
